══════════════════════════════════════
ПІДКЛЮЧЕННЯ FIREBASE (для реальної роботи)
══════════════════════════════════════
Щоб замовлення з телефонів клієнтів одразу з’являлись у персоналу:

1. https://console.firebase.google.com/ → Create project
2. Authentication → Sign-in method → Email/Password → Enable
3. Authentication → Users → Add user (email + пароль для працівників)
4. Firestore Database → Create → production → europe-west (або nearer)
5. Firestore → Rules:

   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /orders/{id} {
         allow create: if true;
         allow read, update, delete: if request.auth != null;
       }
     }
   }

6. Project settings → Your apps → Web → скопіюй firebaseConfig
7. Встав у файл firebase-config.js
8. Постав USE_FIREBASE = true
9. Готово. В адмінці логін = email користувача Firebase.

Безкоштовний план Spark вистачає для невеликого закладу.
